# ⚙️ Turbine Health Monitoring & Failure Forecasting 

## 📌 Project Overview

This project focuses on analyzing turbine operational and sensor data to monitor equipment health and predict potential failure types using machine learning techniques.

The objective is to support predictive maintenance strategies by identifying early warning signs of equipment failure, reducing downtime, and improving operational efficiency.

The project follows a complete end-to-end machine learning workflow, transforming raw sensor data into actionable insights and predictive models.

---

## 🎯 Business Objectives

- Monitor turbine health using operational sensor data.
- Detect early indicators of equipment failure.
- Classify turbine fault types accurately.
- Support proactive maintenance and reduce unexpected downtime.
- Improve maintenance planning and operational reliability.

## 📂 Dataset Description

The dataset contains turbine operational measurements and sensor readings, including:

- Temperature
- Pressure
- Vibration Levels
- Rotational Speed
- Operational Load
- Sensor Measurements
- Failure Labels

---

## 🔍 Analysis Performed

### Data Preparation
- Handled missing values and inconsistent records.
- Removed or treated outliers.
- Performed feature engineering and preprocessing.
- Standardized data for model training.

### Exploratory Data Analysis
- Analyzed feature distributions.
- Studied relationships between sensor variables.
- Investigated patterns associated with turbine failures.
- Performed correlation analysis.

### Machine Learning Models
The following models were trained and evaluated:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- XGBoost Classifier

### Model Evaluation
Models were evaluated using:

- Accuracy Score
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Classification Report

---

## 📈 Key Insights

- Vibration and temperature emerged as the strongest indicators of turbine failures.
- Ensemble learning models significantly outperformed traditional models.
- Random Forest and XGBoost achieved the best predictive performance.
- Certain sensor combinations strongly correlated with specific failure categories.
- Early failure prediction can substantially reduce maintenance costs and production downtime.
